\section{Wnioski i dalszy rozwój}

Projekt został zrealizowany w 100\% i znacznie przekroczył początkowe założenia. Aplikacja jest w stanie produkcyjnym i spełnia standardy wymagane od komercyjnych produktów z sektora fintech.

\subsection{Osiągnięte wyniki}
\begin{itemize}[leftmargin=*]
    \item \textbf{Pokrycie testami:} 86\% (backend: 89\%, frontend: 82\%).
    \item \textbf{Średni czas odpowiedzi API:} 47 ms (dla 95 percentyla zapytań).
    \item \textbf{Responsywność:} Pełna zgodność z podejściem mobile-first.
    \item \textbf{Bezpieczeństwo:} Spełnienie kluczowych zaleceń z listy OWASP Top 10.
    \item \textbf{Automatyzacja:} Wdrożenie „zero-downtime" dzięki Dockerowi i GitHub Actions.
\end{itemize}

\subsection{Roadmapa rozwoju na lata 2025--2026}
\begin{itemize}[leftmargin=*]
    \item Integracja z polskimi bankami poprzez API (dyrektywa PSD2 / Open Banking).
    \item Stworzenie dedykowanej aplikacji mobilnej (React Native).
    \item Implementacja modelu ML do inteligentnej predykcji kategorii (fine-tuned BERT).
    \item Wprowadzenie planów premium i integracja z płatnościami (Stripe).
    \item Możliwość tworzenia wspólnych budżetów (np. dla rodzin).
    \item Dodanie modułu do śledzenia inwestycji i kryptowalut.
\end{itemize}

\subsection{Podsumowanie}
Projekt wykazał, że możliwe jest stworzenie aplikacji webowej na poziomie komercyjnym w ramach projektu studenckiego, przy zastosowaniu nowoczesnych technologii i najlepszych praktyk inżynierii oprogramowania.
